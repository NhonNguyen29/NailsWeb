# Nails Salon — 10 Index Templates & Role-Based Admin/Staff Portal

A curated collection of **10 distinct English Nail Salon website templates** (`index-1.html` – `index-10.html`), a visual Showcase hub (`index.html`), and a live-synced **Admin & Staff Portal** (`admin.html`).

## Included Pages & Features
- **Showcase Hub** (`index.html`): Compare all 10 themes side-by-side with live previews.
- **10 Distinct Themes** (`index-1.html` → `index-10.html`):
  1. Maison Rose (Parisian Rose Gold & Floral Filigree)
  2. Onyx & Gold (Dark Mode Art Deco Haute Couture)
  3. Kanso Studio (Japanese Minimalist Seigaiha Wave)
  4. Botanica Spa (Organic Sage & Eucalyptus Foliage)
  5. Blush Bar (Pastel Pink Sparkles & Nail Bar)
  6. Vogue Atelier (Monochrome Swiss Editorial Grid)
  7. Coastal Pearl (Ocean Wave & Pearl Shimmer)
  8. Velvet Bordeaux (Deep Burgundy Baroque Filigree)
  9. Terracotta Sun (Bohemian Clay & Desert Arches)
  10. Aura Chrome (Futuristic Y2K Lavender & Chrome)
- **Full Salon Sections (English)**: Home, Gallery (+ Lightbox), Menu, Contact Us, Date-Based Booking, and interactive JavaScript Call Us modal.
- **Role-Based Portal** (`admin.html`):
  - **Admin**: Full control — add/edit/delete services, gallery, all text/site info, upload images, manage bookings/callbacks/messages.
  - **Staff**: Restricted to changing **images** and **service prices** only (`403 Forbidden` for all Admin-only sections).

## Deploy on Vercel
Import this GitHub repository in [Vercel](https://vercel.com/new) with **Framework Preset: Other** and Root Directory `./`. No build step required.
